## 3. Kiến trúc & Thiết kế kỹ thuật

### 3.1. Production Catalog Seeder (`src/scripts/seed_production_catalog.ts`)
- Seed bộ công thức hoàn chỉnh đa dạng ẩm thực 3 miền Bắc - Trung - Nam, đủ cả 3 vai trò:
  - Món mặn (`MAIN`): Thịt ba chỉ kho tiêu, Gà rang gừng lá chanh, Cá basa kho tộ, Sườn xào chua ngọt, Thịt kho tàu nước dừa.
  - Món canh (`SOUP`): Canh rau ngót thịt băm, Canh chua cá lóc miền Tây, Canh sườn nấu sấu, Canh bí đao nấu tôm, Canh cua rau đay.
  - Món rau/xào (`SIDE`): Rau muống xào tỏi, Đậu hũ sốt cà chua, Bắp cải xào cà chua, Đậu que xào tỏi, Nộm dưa leo tai heo.
- Mỗi công thức đều có:
  - Dish & aliases.
  - Tác giả và cờ `isCookTested = true`, `isEditorialReviewed = true`, `status = 'PUBLISHED'`.
  - Nguyên liệu chi tiết (định lượng, đơn vị, phân loại quầy chợ, `scalePolicy`, cách sơ chế).
  - Các bước nấu (`phaseName`, `timerSeconds`, `tipText`, hướng dẫn chi tiết).
  - Phân loại Taxonomies (Vùng miền, Phương pháp nấu, Mục đích bữa ăn).

### 3.2. Backup & Restore Scripts (`scripts/backup_db.sh`, `scripts/restore_db.sh`)
- `scripts/backup_db.sh`: Chạy `docker exec angimom_postgres pg_dump` hoặc `pg_dump` cục bộ, lưu vào thư mục `backups/angimom_backup_YYYYMMDD_HHMMSS.sql`.
- `scripts/restore_db.sh`: Khôi phục database từ file backup chỉ định.

### 3.3. E2E Audit & Gate Verification Script (`src/scripts/test_p3_pilot_gate.ts`)
- Kiểm thử tự động toàn diện tích hợp cả 4 luồng nghiệp vụ.
- Diễn tập Backup & Restore Drill: Kiểm tra tạo file backup, ghi dữ liệu, restore và đối soát tính toàn vẹn.
- Kiểm tra toàn bộ 197 test cases trước đó.
