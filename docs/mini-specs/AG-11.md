## 1. Context
- Bắt buộc đọc: [AN_GI_MOM_MASTER_PLAN.md](../AN_GI_MOM_MASTER_PLAN.md) (§6.2, §7), [SECURITY.md](../SECURITY.md), [DATA_MODEL.md](../DATA_MODEL.md), [DECISIONS.md](../DECISIONS.md) (D21, D29, D30).
- Trạng thái hiện tại: Đã hoàn thành lược đồ cơ sở dữ liệu ẩm thực và migration SQL (AG-10). Dự án bước vào bước thứ ba của Phase P2: **Xây dựng hệ thống định danh (Identity) và phân quyền (Authorization)** để bảo vệ các chức năng quản trị danh mục và kiểm duyệt xuất bản công thức (Invariants §5.1).
- Nguyên tắc bảo mật bắt buộc (SECURITY.md):
  - Cookie session phải có cờ `HttpOnly`, `SameSite=Lax`, `Secure` (trên production HTTPS).
  - Tuyệt đối không lưu mật khẩu dạng plain text; băm mật khẩu bằng thuật toán mật mã tiêu chuẩn (PBKDF2/scrypt hoặc bcrypt).
  - Không để lộ thông tin nhạy cảm (password hash, secret) trong API response.
  - Phân quyền theo vai trò (RBAC): `ADMIN`, `EDITOR`, `COOK`.

## 2. Invariants & Scope Boundaries
- **Phân định vai trò nghiệp vụ**:
  - `ADMIN`: Quản lý tài khoản người dùng, phân quyền, cấu hình hệ thống.
  - `EDITOR`: Biên tập, chỉnh sửa nguyên liệu, phân loại taxonomies, kiểm duyệt và xuất bản công thức (`SUBMITTED` $\rightarrow$ `APPROVED` $\rightarrow$ `PUBLISHED`).
  - `COOK`: Người dùng thông thường trải nghiệm món ăn, lên mâm cơm gia đình, lưu công thức cá nhân.
- **Phạm vi triển khai**:
  - Module quản lý session nhẹ, an toàn, độc lập không phụ thuộc dịch vụ OAuth bên ngoài trong giai đoạn này (hỗ trợ Email + Password trước).
  - Middleware Next.js kiểm soát quyền truy cập đường dẫn `/admin/*` và `/editor/*`.
  - API Routes: `/api/auth/login`, `/api/auth/logout`, `/api/auth/me`.
  - CLI Seeder: Script tạo tài khoản Admin & Editor mẫu ban đầu để phát triển và kiểm thử.

## 3. Implementation Plan
1. **Mở rộng bảng `users`**:
   - Thêm trường `password_hash` vào bảng `users` trong `src/lib/db/schema.ts` (nullable để hỗ trợ OAuth sau này nếu cần).
   - Chạy `npm run db:generate` để tạo migration bổ sung.
2. **Cơ chế Mã hóa & Quản lý Session**:
   - Viết module tiện ích bảo mật `src/lib/auth/password.ts`: Băm và so sánh mật khẩu an toàn.
   - Viết module session `src/lib/auth/session.ts`: Đọc/ghi cookie session có chữ ký mật mã (HMAC-SHA256).
3. **API Endpoints**:
   - `src/app/api/auth/login/route.ts`: Xác thực email/mật khẩu, thiết lập cookie session.
   - `src/app/api/auth/logout/route.ts`: Xóa cookie session.
   - `src/app/api/auth/me/route.ts`: Lấy thông tin người dùng hiện tại từ session.
4. **Middleware Bảo vệ Tuyến đường (Route Guarding)**:
   - `src/middleware.ts`: Kiểm tra session cookie; chuyển hướng `/login` nếu chưa đăng nhập khi truy cập `/admin/*` hoặc `/editor/*`.
5. **Giao diện Đăng nhập & CLI Seed**:
   - Trang `/login` (`src/app/login/page.tsx`): Form đăng nhập chuẩn thiết kế Warm Kitchen.
   - Script CLI `src/scripts/seed_admin.ts`: Tạo tài khoản Admin/Editor mặc định.
