## 1. Mục tiêu & Giới hạn phạm vi (R8)

### 1.1 Mục tiêu
1. **Thiết lập giá cho công thức Chợ**: Món lẻ 0đ (miễn phí) hoặc từ 10.000đ – 200.000đ (chỉ Người nấu Bậc 2 hoặc Admin có quyền đặt giá).
2. **Bộ công thức (Bundles / Combo)**: Cho phép người nấu gom 2–50 món thành gói với mức giá ưu đãi (30.000đ – 1.000.000đ).
3. **Bảo vệ nội dung phía Server (Server-Side Content Gating)**:
   - Khi người xem **chưa sở hữu**: Tuyệt đối **không trả về tên nguyên liệu, định lượng và các bước nấu** trong API hoặc Server Component. Chỉ gửi metadata tổng quan (ảnh, tên món, tác giả, mô tả, khẩu phần gốc, thời gian nấu, số sao, giá).
   - Khi người xem **đã sở hữu** (hoặc là tác giả, hoặc là món Bếp Mom miễn phí): Gửi đầy đủ dữ liệu, mở khóa toàn bộ tính năng co giãn khẩu phần, ghép mâm, xuất giỏ đi chợ, chế độ nấu bếp.
4. **Cơ chế trải nghiệm thử nghiệm (Zero-Money Claiming)**:
   - Do chưa có pháp nhân/cổng thanh toán (dành cho R9), R8 cung cấp cơ chế: Người dùng đăng nhập có thể bấm **"Mở khóa dùng thử (Miễn phí)"** để nhận quyền truy cập (`PROMO_CLAIM`), giúp kiểm chứng trọn vẹn luồng UX mà không phát sinh rủi ro tài chính/pháp lý.

### 1.2 Ngoài phạm vi R8
- Cổng thanh toán thật (MoMo, VietQR, PayOS, ngân hàng) -> R9.
- Đơn hàng, hóa đơn điện tử, đối soát tiền -> R9.
- Ví người bán, giải ngân, khấu trừ thuế sàn TMĐT -> R10.

## 2. Kiến trúc Bảo Mật & Ranh Giới Quyền Sở Hữu (Entitlement Model)

### 2.1 Ma trận Quyền Truy Cập Công Thức

| Phân loại công thức | Khách vãng lai (Chưa đăng nhập) | Người dùng đăng nhập (Chưa sở hữu) | Chủ sở hữu / Tác giả |
|---|:---:|:---:|:---:|
| **Bếp Mom (`EDITORIAL`)** | Mở đầy đủ 100% | Mở đầy đủ 100% | Mở đầy đủ 100% |
| **Chợ công thức (Miễn phí `isFree = true`)** | Mở đầy đủ 100% | Mở đầy đủ 100% | Mở đầy đủ 100% |
| **Chợ công thức (Có phí `price > 0`)** | **KHÓA (Gated)** — Ẩn nguyên liệu & các bước | **KHÓA (Gated)** — Hiện nút "Nhận thử nghiệm" | **Mở đầy đủ 100%** |

### 2.2 Quy tắc Server-Side Gating (Không leak dữ liệu qua CSS)
- **Hàm gating trung tâm**: `filterRecipeForViewer(recipe, viewerId)`
- Khi `isGated = true`:
  - `ingredients: []` (Mảng rỗng)
  - `steps: []` (Mảng rỗng)
  - `tips: null`
  - `videoUrl: null`
  - `isGated: true`
  - `gatedReason: 'REQUIRES_PURCHASE'`

## 3. Lược đồ Cơ Sở Dữ Liệu (Schema)

### 3.1 Cột bổ sung trong bảng `recipes`
- `price`: `integer('price').notNull().default(0)` (VNĐ, bội số của 1.000)
- `isFree`: `boolean('is_free').notNull().default(true)`

### 3.2 Bảng `recipe_bundles`
- `id`: serial primary key
- `creatorId`: integer references `users.id` on delete cascade
- `slug`: text unique not null
- `title`: text not null
- `description`: text
- `coverImage`: text
- `price`: integer not null default 30000
- `status`: text not null default 'DRAFT' (DRAFT, PUBLISHED, ARCHIVED)
- `createdAt`, `updatedAt`

### 3.3 Bảng `recipe_bundle_items`
- `id`: serial primary key
- `bundleId`: integer references `recipe_bundles.id` on delete cascade
- `recipeId`: integer references `recipes.id` on delete cascade
- `orderIndex`: integer not null default 0
- Unique index: `(bundle_id, recipe_id)`

### 3.4 Bảng `user_entitlements`
- `id`: serial primary key
- `userId`: integer references `users.id` on delete cascade
- `itemType`: text not null ('RECIPE', 'BUNDLE')
- `recipeId`: integer references `recipes.id` on delete cascade (nullable)
- `bundleId`: integer references `recipe_bundles.id` on delete cascade (nullable)
- `grantedReason`: text not null default 'PROMO_CLAIM' ('CREATOR_OWNER', 'PROMO_CLAIM', 'BUNDLE_EXPANSION', 'ADMIN_GRANT')
- `createdAt`: timestamp with timezone not null default now()
- Unique partial index: `(user_id, recipe_id)` where `item_type = 'RECIPE'`
- Unique partial index: `(user_id, bundle_id)` where `item_type = 'BUNDLE'`

## 4. Danh sách API Endpoints

1. `POST /api/recipes/[id]/claim`:
   - Người dùng đăng nhập nhận quyền sở hữu món ăn miễn phí (thử nghiệm R8).
   - Cấp bản ghi vào `user_entitlements`.
2. `POST /api/bundles/[id]/claim`:
   - Người dùng đăng nhập nhận quyền sở hữu trọn bộ combo món ăn.
   - Tự động mở quyền truy cập cho toàn bộ các món trong combo.
3. `PUT /api/creator/recipes/[id]/pricing`:
   - Dành cho tác giả (Bậc 2 hoặc Admin): đặt giá 10k–200k hoặc đánh dấu miễn phí.
4. `GET/POST /api/creator/bundles`:
   - Dành cho tác giả (Bậc 2 hoặc Admin): tạo và quản lý bộ combo công thức.
