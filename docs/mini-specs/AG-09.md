## 2. Invariants & Stack Specifications (D17, D18, D20)
- **Framework**: Next.js 14+ (App Router, TypeScript).
- **Styling**: Tailwind CSS kế thừa 100% token từ `docs/tokens.css` (bảng màu Kem ấm `#FAF7F0`, Xanh lá `#3F6240`, Cam đất `#B75B35`, chuẩn WCAG 2.2 AA).
- **Icons & Typography**: Phông chữ `Be Vietnam Pro`, icon `lucide-react`.
- **Database & ORM**: PostgreSQL 16 kết hợp `drizzle-orm` + `drizzle-kit` (nhẹ, typesafe, cold-start nhanh, tối ưu tài nguyên VPS đơn người vận hành).
- **Đóng gói & Triển khai**:
  - `Dockerfile` multi-stage (builder $\rightarrow$ runner với alpine / distroless) tối ưu kích thước image (<150MB).
  - `docker-compose.yml` gồm dịch vụ: `web` (Next.js), `db` (Postgres 16), `caddy` (Reverse proxy tự động HTTPS).
  - `.env.example` và quản lý cấu hình môi trường chặt chẽ, không hardcode credentials.

## 3. Implementation Plan
1. **Khởi tạo cấu trúc dự án Next.js**:
   - `src/app/layout.tsx`: Layout gốc tích hợp font Be Vietnam Pro, SEO metadata tiếng Việt.
   - `src/app/page.tsx`: Landing page chào đón kế thừa nhận diện thương hiệu từ Prototype.
   - `src/app/globals.css`: Tích hợp Design Tokens từ `docs/tokens.css`.
   - `tailwind.config.ts`: Cấu hình màu sắc, phông chữ, khoảng cách, bo góc đồng bộ hoàn toàn với `tokens.css`.
2. **Cấu hình Database & Drizzle ORM**:
   - `drizzle.config.ts`: Cấu hình schema path `src/lib/db/schema.ts`, dialect `postgresql`.
   - `src/lib/db/index.ts`: Khởi tạo Drizzle client sử dụng `postgres-js`.
3. **Cấu hình Hạ tầng Docker & Caddy**:
   - `Dockerfile`: Multi-stage build (deps, builder, runner).
   - `docker-compose.yml`: Định nghĩa mạng nội bộ an toàn giữa app, DB và Caddy proxy.
   - `Caddyfile`: Reverse proxy cấu hình sẵn SSL tự động.
   - `.env.example`: Mẫu biến môi trường cho môi trường Local và Production.
4. **Kiểm tra và Xác thực**:
   - Kiểm tra `npm run build` biên dịch TypeScript và bundle không lỗi.
   - Kiểm tra `docker-compose config` cú pháp hợp lệ.
