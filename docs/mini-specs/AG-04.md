## 2. Goal
Xây dựng và hoàn thiện hệ thống Design Tokens toàn diện, được kiểm chứng tương phản toán học đạt chuẩn **WCAG 2.2 AA** (chữ thường $\ge$ 4.5:1, chữ lớn $\ge$ 3:1), bổ sung đầy đủ các token semantic (thành công, cảnh báo, lỗi, thông tin), quy chuẩn typography tiếng Việt và xuất file CSS Variables chuẩn làm nền tảng cho toàn bộ các màn hình Prototype (AG-05, AG-06, AG-07).

## 3. Constraints (Guardrails)
1. **Hệ thống trước, màn hình sau**: Mọi component của prototype sau này (thẻ món, nút bấm, ô lọc, modal) đều phải dùng token đã khai báo; tuyệt đối không dùng mã màu hard-coded ngẫu nhiên.
2. **Tuân thủ WCAG 2.2 AA**: Mọi cặp màu văn bản / nền trên giao diện đọc công thức và nấu ăn phải đạt tỷ lệ tương phản tối thiểu 4.5:1 với chữ thường và 3.0:1 với chữ lớn/nút bấm.
3. **Một bộ Icon duy nhất**: Sử dụng Lucide Icons, nét viền 1.75 - 2px, kích thước bậc 16px (nhỏ), 20px (tiêu chuẩn), 24px (tiêu đề/hành động chính).
4. **Tối ưu tiếng Việt**: Kiểm tra hiển thị dấu thanh và dấu chồng (như *"Ướt, Quyết định, Nấu, Khẩu phần"*) ở cỡ chữ nhỏ nhất (12px, 14px), không bị đè dòng hay cụt dấu.
5. **Không thêm animation trang trí nặng nề**: Tuân thủ `prefers-reduced-motion`; hiệu ứng nhẹ nhàng, ưu tiên độ mượt và phản hồi trạng thái tương tác (hover, active, focus-visible).

## 4. Scope
- **A. Bảng màu & Token cốt lõi**:
  - Base colors: Background (`#FAF7F0`), Surface (`#FFFFFF`), Surface Raised (`#F4EFE6`).
  - Text colors: Text Primary (`#253126`), Text Secondary (`#596454`), Text Muted/Tertiary (`#768271`).
  - Brand & Accent: Brand Primary (`#3F6240`), Brand Hover (`#314D32`), Brand Light (`#EAF0EA`), Accent (`#B75B35`), Accent Hover (`#9E4B28`), Accent Deep cho text (`#A94E2A`).
  - Semantic states: Success (`#2E7D32`), Warning (`#D97706`), Error/Destructive (`#DC2626`), Info (`#0284C7`) kèm màu nền và viền tương ứng.
  - Borders: Base Border (`#E5E7DE`), Strong Border (`#D1D6C5`).
- **B. Thang kích thước & Bố cục**:
  - Typography scale: 12px, 14px, 16px (body), 18px, 20px, 24px, 30px, 36px.
  - Spacing scale: 4px, 8px, 12px, 16px, 20px, 24px, 32px, 40px, 48px, 64px.
  - Border radius: sm (4px), md (8px), lg (12px), xl (16px), 2xl (24px), full (9999px).
  - Shadows: Subtle warm elevation (không dùng bóng đen gắt).
- **C. Wordmark & Nhận diện**:
  - Định hình cấu trúc Wordmark "ĂN GÌ MOM" (Font Be Vietnam Pro bold 24px, màu xanh `#3F6240` với chữ "MOM" điểm xuyết cam `#B75B35`) kèm Tagline nhỏ bên dưới.
- **D. Xuất bản tài nguyên**:
  - Cập nhật `docs/DESIGN_SYSTEM.md` thành `approved`.
  - Tạo file `docs/tokens.css` chứa toàn bộ biến CSS root variables sẵn sàng nhúng vào prototype.
- **E. Tests**: Script Python kiểm tra độ tương phản tự động toàn bộ ma trận màu.

## 5. Audit Before Build
- Hiện tại bảng màu trong Master Plan §6.3 thiếu token `text tertiary` và các màu semantic (success, warning, error, info).
- Accent `#B75B35` trên nền kem `#FAF7F0` đạt 4.30:1 (chưa đạt 4.5:1 cho chữ thường). -> **Giải pháp**: Dùng `#B75B35` cho nút bấm / badge (chữ trắng trên nền cam đạt 4.60:1 AA), và bổ sung `#A94E2A` (đạt 4.96:1 AA) khi dùng làm link văn bản trên nền kem.
- Chưa có file CSS biến để dùng trực tiếp trong code.

## 6. Design Choice
- Chuẩn hóa CSS Custom Properties (`--bg-primary`, `--text-primary`, `--brand-primary`...) theo format tương thích trực tiếp với Tailwind CSS và shadcn/ui.
- Định nghĩa rõ quy ước trạng thái tương tác: `hover`, `active`, `focus-visible` (ring 2px xanh `#3F6240` có offset 2px).

## 7. Test Plan
- Chạy script kiểm tra tương phản tự động đảm bảo 100% các cặp màu chữ/nền công bố đều đạt chuẩn WCAG 2.2 AA.
- Kiểm tra tính đầy đủ của file `docs/tokens.css`.
- Đảm bảo tính nhất quán với `PRODUCT_BRIEF.md` và `DECISIONS.md`.

## 8. Success Criteria
- Toàn bộ ma trận token màu đạt WCAG 2.2 AA có bằng chứng số liệu.
- `docs/tokens.css` được tạo lập đầy đủ biến.
- `DESIGN_SYSTEM.md` được nâng cấp thành phiên bản chính thức, sẵn sàng cho AG-05 (Discovery Prototype).

## 9. Stop Conditions
Nếu phát hiện cặp màu cốt lõi không thể đạt tương phản tối thiểu hoặc có yêu cầu đổi phong cách nhận diện trái với D09: dừng và xin ý kiến.
