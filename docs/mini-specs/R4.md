## 1. Context

- **Hiện trạng:**
  - File `drizzle/meta/_journal.json` ban đầu chỉ ghi nhận 3 migration đầu tiên (`0000_dry_orphan`, `0001_happy_talon`, `0002_ag15_publishing_revision`), bỏ sót 8 migration từ `0003` đến `0010`.
  - Hậu quả: Lệnh chuẩn của Drizzle ORM (`npx drizzle-kit migrate` hoặc `npm run db:migrate`) chỉ chạy 3 file đầu tiên, bỏ sót các bảng quan trọng (`saved_recipes`, `recipe_reports`, `dish_variants`, `cooked_feedback`, `ingredient_nutrition`, `meal_diary`, `pantry_items`, `meal_plans`).
  - Script triển khai production (`scripts/deploy_production.sh`) sử dụng vòng lặp thô qua `psql` với cờ `2>/dev/null || true` và `sleep 5`, dẫn đến việc lỗi SQL bị nuốt chửng, không có cơ chế fail-closed và không lưu trạng thái migration chuẩn Drizzle.
  - Trang nấu `/cong-thuc/[slug]/nau` kích hoạt cảnh báo `NEXT_STATIC_GEN_BAILOUT` do đọc `searchParams` ngoài `<Suspense>`.
  - Modal đổi món `SwapDishModal.tsx` mắc lỗi ESLint `react-hooks/set-state-in-effect` và chưa được đưa vào phạm vi kiểm tra `lint:scoped`.

## 2. Goals

1. **Đồng bộ toàn diện Migration Journal**: Cập nhật `drizzle/meta/_journal.json` đủ 11 mục (`0000` đến `0010`), đảm bảo `drizzle-kit migrate` dựng đầy đủ 18 bảng CSDL trên DB sạch mà không cần workaround.
2. **Triển khai Fail-Closed & Idempotent**: Viết script `scripts/migrate_production.js`, cập nhật `scripts/deploy_production.sh`: chờ Postgres bằng `pg_isready` (có retry), kiểm tra bảng `drizzle.__drizzle_migrations`, thực thi tuần tự, dừng ngay lập tức nếu có bất kỳ lỗi SQL nào (không dùng `|| true`).
3. **Triệt tiêu cảnh báo Prerender**: Bọc component đọc `searchParams` trong trang nấu `/cong-thuc/[slug]/nau` bằng `<Suspense fallback={<CookingLoadingShell />}>`.
4. **Chuẩn hóa ESLint**: Tách component trong `SwapDishModal.tsx` để loại bỏ `set-state-in-effect`, đưa cả `SwapDishModal.tsx` và `cong-thuc/[slug]/nau/page.tsx` vào `lint:scoped` với kết quả 0 errors, 0 warnings.

## 3. Constraints

- Giữ nguyên toàn bộ schema và dữ liệu hiện có trong các tệp `drizzle/*.sql`.
- Đảm bảo tính tương thích hai chiều giữa `drizzle-kit migrate` và script triển khai Docker.
- Không để lộ secret ra repo/CI.
- Mọi thay đổi phải được kiểm chứng tự động qua toàn bộ test suites.

## 4. Scope & Implementation

### A. Đồng bộ Drizzle Journal
- Bổ sung 8 entry vào `drizzle/meta/_journal.json`:
  - `0003_ag20_saved_recipes`
  - `0004_ag29_ai_provenance`
  - `0005_ag32_recipe_reports`
  - `0006_ag33_dish_variants_stories`
  - `0007_ag34_cooked_feedback`
  - `0008_ag35_36_nutrition_engine`
  - `0009_ag37_38_meal_diary`
  - `0010_ag39_40_41_p7_catalog_pantry_planner`
- Đã kiểm chứng: Tạo DB trống `angimom_migration_test`, chạy `npx drizzle-kit migrate` tạo đủ 18 bảng và ghi nhận đủ 11 bản ghi migration.

### B. Nâng cấp Script Deploy Production
- Tạo `scripts/migrate_production.js` tương thích hoàn toàn với schema của Drizzle (`drizzle.__drizzle_migrations`).
- Nâng cấp `scripts/deploy_production.sh`:
  - Thay thế `sleep 5` bằng vòng lặp kiểm tra `pg_isready` tối đa 30 lần (60 giây).
  - Loại bỏ hoàn toàn `2>/dev/null || true`.
  - Gọi `node scripts/migrate_production.js` với chế độ fail-closed.

### C. Khắc phục Prerender Bailout
- Tại `src/app/cong-thuc/[slug]/nau/page.tsx`:
  - Di chuyển việc `await searchParams` vào `CookingModeContent`.
  - Bọc `CookingModeContent` trong `<Suspense fallback={<CookingLoadingShell />}>`.
  - Kết quả: `next build` render tĩnh 55/55 routes, không còn log `NEXT_STATIC_GEN_BAILOUT`.

### D. Chuẩn hóa ESLint Scoped
- Tách `SwapDishModal` thành modal cha và `SwapDishModalContent` (keyed by `role`), khởi tạo `isLoading = true`, fetch dữ liệu bất đồng bộ mà không cần gọi `setState` đồng bộ bên trong effect body.
- Thêm `SwapDishModal.tsx` và `cong-thuc/[slug]/nau/page.tsx` vào `npm run lint:scoped`.
- Dọn dẹp các biến/import thừa, đạt 0 errors, 0 warnings.
