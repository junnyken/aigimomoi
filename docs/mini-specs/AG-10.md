## 2. Invariants & Schema Design
1. **Enums miền**:
   - `recipe_publish_status`: `DRAFT`, `SUBMITTED`, `APPROVED`, `PUBLISHED`, `ARCHIVED`
   - `meal_role`: `MAIN`, `SOUP`, `SIDE`, `DISH_1`, `DISH_2`, `DISH_3`, `SNACK`, `DRINK`, `DESSERT`
   - `scale_policy`: `LINEAR`, `FIXED`, `MANUAL_ADJUST`
   - `taxonomy_type`: `CUISINE_REGION`, `COOKING_METHOD`, `DIET_PREFERENCE`, `OCCASION`
2. **Bảng dữ liệu cốt lõi**:
   - `users`: Quản lý tác giả, biên tập viên, quản trị viên.
   - `recipes`: Thông tin món ăn, slug duy nhất, vai trò, thời gian nấu, mức độ khó, calo, cờ nấu thử, cờ kiểm chứng dinh dưỡng.
   - `recipe_aliases`: Tên gọi địa phương/đồng nghĩa phục vụ tìm kiếm chuẩn xác.
   - `ingredients`: Từ điển nguyên liệu dùng chung, phân loại, cờ gia vị sẵn có trong bếp (`is_pantry_staple`).
   - `recipe_ingredients`: Chi tiết nguyên liệu của món ăn, định lượng cơ sở, đơn vị, `scale_policy`, cách sơ chế `preparation`, thứ tự hiển thị.
   - `cooking_steps`: Các bước nấu theo giai đoạn, thời gian đếm ngược an toàn `timer_seconds`, mẹo nấu `tip_text`.
   - `taxonomies` & `recipe_tags`: Gắn nhãn miền Bắc/Trung/Nam, luộc/kho/xào/canh, món giải nhiệt, v.v.
   - `meals` & `meal_items`: Cấu trúc mâm cơm 3 món chuẩn hóa.
3. **Quan hệ (Drizzle Relations)**:
   - `recipesRelations`: 1-nhiều với `recipe_aliases`, `recipe_ingredients`, `cooking_steps`, `recipe_tags`.
   - `ingredientsRelations`: 1-nhiều với `recipe_ingredients`.
   - `taxonomiesRelations`: 1-nhiều với `recipe_tags`.

## 3. Implementation Plan
1. Viết toàn bộ schema hoàn chỉnh vào `src/lib/db/schema.ts`.
2. Tạo file định nghĩa quan hệ Drizzle typesafe vào `src/lib/db/relations.ts`.
3. Cập nhật `src/lib/db/index.ts` để nạp cả `schema` và `relations`.
4. Chạy `npm run db:generate` để Drizzle Kit tự động sinh file migration SQL trong thư mục `drizzle/`.
5. Viết script kiểm thử schema `scratch/test_schema.ts` hoặc script node để kiểm tra cú pháp và tính toàn vẹn của các bảng.
