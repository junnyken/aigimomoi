  - Giải quyết câu hỏi mở **O4**: Chốt kiến trúc nhà cung cấp AI theo mô hình Adapter đa nền tảng (`Gemini`, `OpenAI-compatible`, và `Mock/Heuristic Fallback`).
  - **Ranh giới bảo mật Server-only (Server Boundary)**: Tuyệt đối không để lộ AI API Key ra client-side (`NEXT_PUBLIC_`), mọi tác vụ gọi AI đều được thực thi bảo mật tại Next.js Route Handlers / Server Actions.
  - **Quản lý Ngân sách & Hạn mức (Budget Cap & Rate Limit)**:
    - Giới hạn token đầu ra nghiêm ngặt (`maxOutputTokens: 1000-1500`).
    - Giới hạn thời gian phản hồi (Timeout $\le 10\text{s}$) chống treo tiến trình.
    - Cơ chế giới hạn tần suất (Rate Limiter: ví dụ tối đa 10 requests / phút / IP) chống lạm dụng chi phí.
  - **Graceful Fallback & Circuit Breaker**:
    - Khi không có API key, API key hết hạn, quota vượt ngưỡng hoặc AI phản hồi lỗi: Hệ thống tự động chuyển sang `MockHeuristicProvider` dựa trên catalog có sẵn trong database mà không bao giờ làm sập ứng dụng hay báo lỗi 500 cho người dùng.

## 2. Invariants & Scope Boundaries

### Invariants bắt buộc (Gate P4):
1. **Server-only Secrets**:
   - `GEMINI_API_KEY` hoặc `OPENAI_API_KEY` không bao giờ xuất hiện trong client bundle, log stdout (kế thừa Redaction từ AG-25), hay network request trên trình duyệt.
2. **Không gây chi phí không kiểm soát**:
   - Áp đặt trần token (Token Cap) cho mọi prompt.
   - Timeout 10s tự động ngắt kết nối nếu AI provider bị nghẽn mạng.
3. **Graceful Degradation (Không làm hỏng luồng người dùng)**:
   - Nếu AI provider trả về lỗi hoặc timeout, API tự động fallback sang kết quả phân tích heuristic từ DB có sẵn. Người dùng vẫn nhận được gợi ý món ăn hợp lệ.
4. **Không tạo đường tắt Publish (Invariants §5.1)**:
   - Module AI Provider chỉ là lớp sinh nội dung thô hoặc gợi ý; không có quyền can thiệp thay đổi trạng thái `status = 'PUBLISHED'` trong DB.

### Ngoài phạm vi AG-27:
- Giao diện UI gợi ý mâm cơm AI (thuộc **AG-28**).
- Giao diện AI soạn thảo bản nháp công thức cho biên tập viên (thuộc **AG-29**).

## 3. Kiến trúc & Thiết kế kỹ thuật

### 3.1. AI Provider Adapter Interface (`src/lib/ai/types.ts`)
```typescript
export interface AiCompletionOptions {
  prompt: string;
  systemInstruction?: string;
  temperature?: number;
  maxTokens?: number;
  timeoutMs?: number;
  jsonMode?: boolean;
}

export interface AiCompletionResult {
  text: string;
  provider: 'gemini' | 'openai' | 'mock';
  model: string;
  tokensUsed?: {
    prompt: number;
    completion: number;
    total: number;
  };
}

export interface AiProvider {
  name: string;
  isAvailable(): boolean;
  generateCompletion(options: AiCompletionOptions): Promise<AiCompletionResult>;
}
```

### 3.2. Implementations
1. **Gemini Adapter (`src/lib/ai/geminiProvider.ts`)**:
   - Tích hợp chuẩn Google Generative AI REST API (`gemini-1.5-flash` / `gemini-2.0-flash`).
2. **OpenAI-Compatible Adapter (`src/lib/ai/openaiProvider.ts`)**:
   - Tương thích OpenAI / OpenRouter / DeepSeek API.
3. **Mock Heuristic Adapter (`src/lib/ai/mockProvider.ts`)**:
   - Fallback thông minh dựa trên logic nội bộ của hệ thống khi không có API key.

### 3.3. AI Gateway & Budget Manager (`src/lib/ai/gateway.ts`)
- Quản lý thứ tự ưu tiên provider (Primary $\to$ Fallback $\to$ Mock).
- Bộ đếm và kiểm soát ngân sách:
  - Kiểm tra `RATE_LIMIT_PER_MINUTE`.
  - Bọc timeout `AbortController` (mặc định 10s).
  - Tự động bắt lỗi và fallback an toàn.
