## 2. Invariants & Scope Boundaries

### Invariants bắt buộc (§6.7):
1. **Trải nghiệm liền mạch không ép buộc login (§6.7)**:
   - Khách vãng lai bấm nút Lưu sẽ lưu ngay vào `localStorage` của trình duyệt, không bật popup ép đăng nhập chặn người dùng.
   - Khi người dùng đăng nhập tài khoản, client tự động kích hoạt API `/api/saved-recipes/sync` để gộp danh sách món đã lưu vào tài khoản.
2. **Chỉ hiển thị các món `PUBLISHED` trong danh sách đã lưu**:
   - Nếu một công thức đã lưu bị tác giả chuyển về trạng thái `DRAFT` hoặc `ARCHIVED`, danh sách `/da-luu` sẽ tự động ẩn món đó để đảm bảo Invariants §5.1.
3. **An toàn dữ liệu & xác thực**:
   - Mỗi người dùng chỉ xem và quản lý danh sách món đã lưu của chính mình (kiểm tra `session.userId` chặt chẽ).
   - Ràng buộc Unique trên `(userId, recipeId)` chống lưu trùng lặp.
4. **Phản hồi tức thì (Optimistic UI)**:
   - Nút Bookmark đổi trạng thái ngay khi bấm để tạo cảm giác mượt mà tức thì cho người dùng.

## 3. Architecture & Implementation Plan

### 3.1. Database Schema & Migration (`src/lib/db/schema.ts`)
- Thêm bảng `saved_recipes`:
  ```typescript
  export const savedRecipes = pgTable('saved_recipes', {
    id: serial('id').primaryKey(),
    userId: integer('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
    recipeId: integer('recipe_id').notNull().references(() => recipes.id, { onDelete: 'cascade' }),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  }, (table) => [
    uniqueIndex('saved_recipes_user_recipe_idx').on(table.userId, table.recipeId),
    index('saved_recipes_user_idx').on(table.userId),
  ]);
  ```
- Tạo và chạy migration Drizzle `0003_ag20_saved_recipes.sql`.

### 3.2. API Endpoints (`src/app/api/saved-recipes/route.ts`)
- `GET /api/saved-recipes`: Trả về danh sách slug/id các món đã lưu của user hiện tại.
- `POST /api/saved-recipes`: Lưu món ăn (body: `{ recipeId: number }` hoặc `{ slug: string }`).
- `DELETE /api/saved-recipes`: Bỏ lưu món ăn (query/body: `{ recipeId: number }`).
- `POST /api/saved-recipes/sync`: Nhận mảng slugs từ `localStorage` và insert `onConflictDoNothing()`.

### 3.3. Client Storage & Bookmark Hook (`src/lib/recipes/savedRecipesClient.ts`)
- Client helper quản lý `localStorage` cho khách chưa đăng nhập và đồng bộ khi có session.
- Component `BookmarkButton.tsx`: Nút icon bookmark dùng chung trên `RecipeCard` và Hero trang chi tiết.

### 3.4. Trang công thức đã lưu (`src/app/da-luu/page.tsx`)
- Server Component / Client Component hiển thị danh sách các món ăn đã lưu.
- Empty state: Khi danh sách trống, hiển thị hướng dẫn lưu món và nút "Khám phá món ăn" trỏ tới `/mon-an`.
- Cập nhật Header navigation thêm link `/da-luu` ("Món đã lưu").

### 3.5. Kịch bản kiểm thử tự động (`src/scripts/test_saved_recipes.ts`)
- Kiểm thử lưu/bỏ lưu món ăn trong DB với user thật.
- Kiểm thử ràng buộc unique (không bị lỗi khi lưu trùng).
- Kiểm thử chỉ hiển thị công thức `PUBLISHED`.
- Kiểm thử API endpoint với authentication.
- Typecheck và build production `npm run build` pass.
