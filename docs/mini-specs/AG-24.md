## 2. Invariants & Scope Boundaries

### Invariants bắt buộc (§5.1, §6.5, §6.7):
1. **Ranh giới lập chỉ mục (Index Boundaries, Invariants §5.1)**:
   - Tuyệt đối không đưa các slug thuộc bản nháp (`DRAFT`, `SUBMITTED`, `NEEDS_CHANGES`) hoặc bản cũ (`ARCHIVED`) vào Sitemap.
   - Các trang quản trị biên tập (`/editor/*`), API (`/api/*`), đăng nhập (`/login`) phải bị chặn bằng robots Disallow và `noindex`.
2. **Tuân thủ chuẩn Schema.org Recipe**:
   - Định dạng thời gian chuẩn ISO 8601 Duration (`PT15M`, `PT1H`, v.v.).
   - Danh sách bước nấu định dạng `HowToStep`.
   - Không chèn mã độc, chuỗi rác hay HTML không an toàn vào JSON-LD.
3. **Canonical URLs đồng nhất**:
   - Mỗi trang có một Canonical URL tuyệt đối chuẩn mực, tránh trùng lặp nội dung khi URL có query parameters.

## 3. Kiến trúc & Thiết kế kỹ thuật

### 3.1. Sitemap Động (`src/app/sitemap.ts`)
- Next.js Metadata Route trả về `MetadataRoute.Sitemap`.
- Truy vấn DB: `select({ slug, publishedAt, updatedAt }) from recipes where status = 'PUBLISHED'`.
- Kết hợp với danh sách route tĩnh (`/`, `/mon-an`, `/meal`, `/da-luu`, `/shopping`).

### 3.2. Robots (`src/app/robots.ts`)
- Next.js Metadata Route trả về `MetadataRoute.Robots`.
- Quy định `rules`:
  - `userAgent: '*'`
  - `allow: '/'`
  - `disallow: ['/editor/', '/api/', '/login']`
- `sitemap: 'https://angimom.vn/sitemap.xml'`

### 3.3. Dữ liệu có cấu trúc JSON-LD (`src/components/seo/RecipeJsonLd.tsx`)
- Nhúng script `type="application/ld+json"` an toàn (không dùng dangerouslySetInnerHTML chứa chuỗi người dùng chưa escape, serialize JSON an toàn).
