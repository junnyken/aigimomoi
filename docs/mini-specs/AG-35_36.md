## 1. Bối cảnh & Mục tiêu
- **Bối cảnh**:
  - Trong các giai đoạn trước (P1..P5), nhãn `isNutritionVerified` luôn bị khóa `false` và `nutritionStatus` mặc định là `NO_DATA` nhằm bảo đảm tính trung thực khoa học, không suy đoán số liệu calo/dinh dưỡng khi chưa có nguồn dữ liệu tin cậy.
  - Bước sang Phase P6, nền tảng bắt đầu xây dựng Engine Dinh Dưỡng Dữ Liệu Chuẩn Việt Nam, đối chiếu trực tiếp từ **Bảng thành phần thực phẩm Việt Nam (Viện Dinh Dưỡng Quốc Gia - Bộ Y Tế)**.
- **Mục tiêu**:
  1. **AG-35 (Nutrition Source Audit & Mapping)**:
     - Tạo bảng `ingredient_nutrition` lưu trữ dữ liệu dinh dưỡng trên 100g phần ăn được (Edible Portion) theo chuẩn Viện Dinh Dưỡng (`VIETNAM_FCT_2007`), USDA hoặc nhãn nhà sản xuất.
     - Phân định rõ tỷ lệ phần ăn được (`edibleRate`): thịt cá có xương, rau củ có rễ/vỏ bỏ đi.
     - **Quy tắc Bất biến Tối thượng Gate P6: Dữ liệu thiếu không được ép thành 0 (`Missing is NOT Zero`)**. Phân biệt `0` (không có chất đó) và `null` (chưa phân tích).
  2. **AG-36 (Recipe Nutrition Calculator)**:
     - Xây dựng thuật toán chuyển đổi đơn vị thực tế trong bếp Việt (`g`, `kg`, `lạng`, `ml`, `thìa cà phê`, `thìa canh`, `bát/chén`, `quả/trái`, `củ/nhánh`) sang gam thực phẩm ăn được.
     - Tính toán tự động:
       - Năng lượng (Kcal), Chất đạm (Protein - g), Chất béo (Lipid - g), Chất bột đường (Carbs - g), Chất xơ (Fiber - g), Natri (Sodium - mg).
       - Tính theo: (1) Toàn bộ nồi nấu (Total Batch); (2) Trên mỗi khẩu phần ăn (`per serving`); (3) Trên 100g thành phẩm.
     - Tính tỷ lệ bao phủ dữ liệu (`coveragePercent`): công khai minh bạch danh sách nguyên liệu chưa có dữ liệu dinh dưỡng để người dùng nắm rõ.
     - Cập nhật nhãn `isNutritionVerified = true` khi độ bao phủ đạt ngưỡng chuẩn (>= 80% khối lượng).

## 2. Invariants & Quy tắc Bất biến (§5.5, Gate P6)
1. **Quy tắc Dữ liệu Thiếu (Missing Data Invariant)**:
   - Nếu một nguyên liệu chưa có số liệu về Natri hoặc Chất xơ, trường đó phải giữ giá trị `null` và hiển thị dấu gạch ngang (`-`) hoặc `Chưa rõ`, TUYỆT ĐỐI KHÔNG gán bằng 0 để tránh gây rủi ro sức khỏe cho bệnh nhân tim mạch, thận, tiểu đường.
2. **Nguồn gốc Có thể Truy vết (Provenance Tracking)**:
   - Dữ liệu dinh dưỡng phải ghi nguồn rõ ràng: `VIETNAM_FCT_2007` (Viện Dinh Dưỡng), `USDA_SR28`, `MANUFACTURER`, `VERIFIED_LAB`.
3. **Phần Ăn Được (Edible Portion / Refuse Rate)**:
   - Trọng lượng nguyên liệu mua về nhân với `edibleRate` trước khi nhân với thành phần dinh dưỡng trên 100g.
4. **Snapshot Cố Định Khi Publish**:
   - Khi công thức tính toán dinh dưỡng, kết quả được lưu dạng Snapshot `nutritionSnapshot` trong `recipes` để không bị hồi tố hay thay đổi đột ngột nếu từ điển nguyên liệu cập nhật sau này.

## 3. Data Model & Migration
Bảng `ingredient_nutrition`:
- `id`: `serial` Primary Key
- `ingredient_id`: `integer` references `ingredients.id` UNIQUE ON DELETE CASCADE
- `source`: `text` NOT NULL DEFAULT 'VIETNAM_FCT_2007'
- `edible_rate`: `double precision` NOT NULL DEFAULT 1.0 (0.1 .. 1.0)
- `calories_100g`: `double precision` (Kcal / 100g)
- `protein_100g`: `double precision` (g)
- `fat_100g`: `double precision` (g)
- `carbs_100g`: `double precision` (g)
- `fiber_100g`: `double precision` (g, nullable)
- `sodium_100g`: `double precision` (mg, nullable)
- `is_verified`: `boolean` NOT NULL DEFAULT false
- `notes`: `text`
- `created_at`: `timestamp with time zone` NOT NULL DEFAULT now()
- `updated_at`: `timestamp with time zone` NOT NULL DEFAULT now()

Bảng `recipes`:
- Thêm cột `nutrition_snapshot`: `jsonb` lưu snapshot kết quả tính toán chi tiết:
  ```json
  {
    "perServing": { "calories": 320, "protein": 24.5, "fat": 18.2, "carbs": 12.0, "fiber": 2.1, "sodium": 650 },
    "totalBatch": { ... },
    "coveragePercent": 95,
    "missingIngredients": ["Hành lá", "Tiêu"],
    "source": "VIETNAM_FCT_2007",
    "calculatedAt": "2026-10-21T00:00:00Z"
  }
  ```

## 4. Architecture & Calculator Engine
Module `src/lib/nutrition/`:
- `units.ts`: Hệ số chuyển đổi đơn vị bếp Việt sang gam.
- `calculator.ts`: Tính tổng dinh dưỡng cho công thức với missing-data rules.
- `seedData.ts`: Dữ liệu dinh dưỡng chuẩn cho các nguyên liệu phổ biến trong bữa cơm gia đình Việt Nam.
